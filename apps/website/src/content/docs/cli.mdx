Run `orion-agent --help` for the grouped list. Output is plain text when piped, with `--json`, or with
`NO_COLOR=1`. Exit codes: 0 ok, 1 failed checks or errors, 2 usage error, 3 needs elevation (run with `sudo`).

<Cmd name="orion-agent status" desc="Show whether this host is reporting, what it is watching, and the next step." open>

| Flag | What it does |
|---|---|
| `--short` | One line, for prompts and cron. |
| `--watch` | Redraw live in place. `q` quits. |
| `--json` | Flat, versioned JSON. |

```sh
orion-agent status
orion-agent status --short
```

</Cmd>

<Cmd name="orion-agent setup" desc="Connect this host and choose what to monitor. Optional: host metrics report without it.">

| Flag | What it does |
|---|---|
| `--core-url URL` | Where your Core is. |
| `--token-file PATH` | File holding the one-time Add server token. |
| `--accept-discovered` | Add every high-confidence suggestion. |
| `--monitor ID` | Add one suggestion, for example `service:nginx`. Repeatable. |
| `--dry-run` | Show the config diff and change nothing. |
| `--yes` | Never ask a question. |

```sh
orion-agent setup
orion-agent setup --core-url https://core.example.com --token-file /secure/path/token --accept-discovered --yes
```

</Cmd>

<Cmd name="orion-agent discover" desc="See what Orion found on this server and could monitor. On a terminal you can pick and add.">

| Flag | What it does |
|---|---|
| `--rescan` | Look again now and show what could not be scanned. |
| `--dismissed` | List what you dismissed. |

```sh
orion-agent discover
orion-agent discover ignore port:5432
orion-agent discover restore port:5432
```

</Cmd>

<Cmd name="orion-agent doctor" desc="Check the agent, Core, discovery, logs and disk, and print the exact fix for anything wrong.">

Exit code 1 when a check fails. `--json` lists each check with id, group, status, message and fix.

```sh
orion-agent doctor
```

</Cmd>

<Cmd name="orion-agent logs" desc="Read agent logs, or follow the logs shipped to Core in a full-screen viewer." open>

| Flag | What it does |
|---|---|
| `--follow`, `-f` | Follow shipped logs live. `↑↓` move, `enter` details, `p` pause, `l` level, `/` search, `q` quits. |
| `--lines N` | How many entries to show. |
| `--level warn` | Only entries at or above a level. |
| `--name nginx` | Only logs from one configured source. |
| `--search text` | Only entries containing text. |
| `--since 1h` | Only entries from the last hour. |

```sh
orion-agent logs --follow --level warn
```

</Cmd>

<Cmd name="orion-agent usage" desc="What apps on this host cost right now: CPU, memory, disk and network, measured from outside.">

| Flag | What it does |
|---|---|
| `--watch` | Redraw live in place. `s` sorts, `q` quits. |
| `--window 3s` | Time between the two samples. |
| `--top N` | Rows shown. |

```sh
orion-agent usage --watch
```

</Cmd>

<Cmd name="orion-agent config" desc="Show where settings come from, compare, validate and edit.">

```sh
orion-agent config show
orion-agent config diff
orion-agent config validate
orion-agent config edit
```

`edit` opens your editor on a copy, checks it, shows what changed and asks before saving. The running agent reloads the new config.

</Cmd>

<Cmd name="orion-agent start | stop | restart" desc="Control the service. Start and restart check config, state and permissions first.">

```sh
sudo orion-agent restart
sudo orion-agent stop --yes
```

`stop` asks once on a terminal. `--yes` skips the question.

</Cmd>

<Cmd name="orion-agent maintenance" desc="Mute alerts for a planned window. It always ends: 24 hours by default, 720 hours at most.">

```sh
orion-agent maintenance down "kernel upgrade" --for 2h
orion-agent maintenance up
```

With no arguments on a terminal, `down` asks why and for how long.

</Cmd>

<Cmd name="orion-agent update" desc="Update safely: the download is verified, the old binary is kept, and a bad update rolls back by itself.">

| Flag | What it does |
|---|---|
| `--version X.Y.Z` | Install a specific release. |
| `--rollback` | Restore the binary that was installed before the last update. |
| `--force` | Reinstall even when already on the target version. |

```sh
sudo orion-agent update
sudo orion-agent update --rollback
```

</Cmd>

<Cmd name="orion-agent token apply" desc="Apply a replacement token when the agent can no longer authenticate. Identity and monitors are kept.">

```sh
orion-agent token apply --token-file /secure/path/replacement-token
orion-agent service restart
```

</Cmd>

<Cmd name="orion-agent emit" desc="Send one log entry from your own script.">

```sh
orion-agent emit --severity error --event backup.failed "nightly backup failed"
```

</Cmd>

<Cmd name="orion-agent run-job" desc="Run a command, ship its output, and ping a heartbeat. The command's own output and exit code pass through.">

```sh
orion-agent run-job --name nightly-backup --heartbeat-token $TOKEN -- /usr/local/bin/backup.sh
```

One summary line on stderr: `✓ nightly-backup  exit 0 · 41 s · 214 lines shipped · heartbeat ok`.

</Cmd>

<Cmd name="orion-agent reconfigure" desc="Create a new local registration. Core will see this machine as a new server.">

```sh
orion-agent reconfigure --token-file /secure/path/add-server-token
```

</Cmd>

<Callout type="warn" title="Use reconfigure sparingly.">It registers the machine as a new server instead of reusing its identity. It needs a fresh one-time Add server token from the Console.</Callout>
