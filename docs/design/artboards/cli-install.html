What it shows

  • Plan first, then one line per step. --dry-run prints only the plan.
  • The one-time enrollment token is in the command, so no config edit is needed.
  • Ends with Doctor and a link to the new server in the Console.

Tokens

  • Background #0c0f0e (dark) or terminal default
  • Accent green #6ee7b7 maps to --color-accent
  • Muted #8b9892, faint #6a7570
  • Truecolor, 256 and 16 colors; NO_COLOR and non-TTY print plain text

Glyphs, never color alone

  • up ● / ok, down ■ / down, degraded ◐ / slow, unknown ○ / ?, maintenance ‖
  • Pass ✓, warn !, fail ✗ always followed by a word
  • Plain mode prints [ok], [warn], [fail]

Errors

  • A tampered download stops at Verify with a red ✗ and the expected and actual hash.
  • Re-running is a no-op and says so.
