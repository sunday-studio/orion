Wizard (huh and bubbletea)

  • Three steps: connect, choose, review. A step counter is in the window title.
  • Focused field has a green left bar ┃; hint text is muted.
  • Discovery rows show a confidence label: high green, medium amber.
  • Review shows a unified diff: additions green, removals red.

Non-interactive

  • The same flow runs from flags or JSON for automation: --core-url, --token, --accept-discovered, --yes.

Tokens

  • Background #0c0f0e (dark) or terminal default
  • Accent green #6ee7b7 maps to --color-accent
  • Muted #8b9892, faint #6a7570
  • Truecolor, 256 and 16 colors; NO_COLOR and non-TTY print plain text

Glyphs, never color alone

  • up ● / ok, down ■ / down, degraded ◐ / slow, unknown ○ / ?, maintenance ‖
  • Pass ✓, warn !, fail ✗ always followed by a word
  • Plain mode prints [ok], [warn], [fail]
