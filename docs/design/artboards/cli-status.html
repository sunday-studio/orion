Status

  • A rounded box (lipgloss) holds the connection facts as aligned key and value pairs.
  • Table uses a muted header and a thin rule; status uses glyph plus word.
  • Works as a normal user through the local control socket, no sudo.

Budgets

  • Cold start under 50 ms for help and version, under 100 ms for status (plan B4).

Tokens

  • Background #0c0f0e (dark) or terminal default
  • Accent green #6ee7b7 maps to --color-accent
  • Muted #8b9892, faint #6a7570
  • Truecolor, 256 and 16 colors; NO_COLOR and non-TTY print plain text

Glyphs, never color alone

  • up ● / ok, down ■ / down, degraded ◐ / slow, unknown ○ / ?, maintenance ‖
  • Pass ✓, warn !, fail ✗ always followed by a word
  • Plain mode prints [ok], [warn], [fail]
