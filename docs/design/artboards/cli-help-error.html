Help (fang on cobra)

  • Commands grouped by intent, not alphabetically. Command names in blue-ish accent, descriptions plain.
  • Fits 80 columns.

Errors

  • Red ERROR badge, one-line summary, the file and line, a caret under the problem, a suggested fix, then the exact command.
  • Plain output keeps the same words with [fail].
  • Exit codes: 0 ok, 1 failed checks, 2 usage, 3 needs elevation.

Tokens

  • Background #0c0f0e (dark) or terminal default
  • Accent green #6ee7b7 maps to --color-accent
  • Muted #8b9892, faint #6a7570
  • Truecolor, 256 and 16 colors; NO_COLOR and non-TTY print plain text

Glyphs, never color alone

  • up ● / ok, down ■ / down, degraded ◐ / slow, unknown ○ / ?, maintenance ‖
  • Pass ✓, warn !, fail ✗ always followed by a word
  • Plain mode prints [ok], [warn], [fail]
