Streaming checklist

  • Each check prints as it finishes; a spinner marks the one running.
  • Every warning and failure prints the exact command to fix it, indented under the line.
  • Summary line counts passes, warnings and failures; exit code is nonzero on failure.

Other forms

  • --json prints a stable schema per check: id, status, message, fix.
  • Non-TTY prints [ok], [warn], [fail] lines with no spinner.

Tokens

  • Background #0c0f0e (dark) or terminal default
  • Accent green #6ee7b7 maps to --color-accent
  • Muted #8b9892, faint #6a7570
  • Truecolor, 256 and 16 colors; NO_COLOR and non-TTY print plain text

Glyphs, never color alone

  • up ● / ok, down ■ / down, degraded ◐ / slow, unknown ○ / ?, maintenance ‖
  • Pass ✓, warn !, fail ✗ always followed by a word
  • Plain mode prints [ok], [warn], [fail]
